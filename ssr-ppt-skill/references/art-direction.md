# 视觉定调与页面设计

用于新建演示或美化版式。已有模板、品牌与用户指定的参考优先；仅改文字或数据时沿用现有视觉体系，不重新设计整套。

## 目标

做出让人记住的演示，而不只是没有错误的演示：

- **有记忆点**：全套有一个可识别的视觉概念和贯穿的母题，去掉 logo 后仍能和通用模板区分开。
- **有高潮**：封面、核心结论和最强证据等 1–3 页（较长演示每个章节至少一页）用最大的尺度反差和最强的视觉，值得单独截图分享。
- **有节奏**：高冲击页、标准内容页、密集阅读页与呼吸页按叙事交替。
- **有精度**：普通内容页可以平静，但对齐、层级、字体和数字处理必须精确。

视觉服务于内容。冲击力来自主次、尺度、构图和素材，而不是阴影、渐变和装饰。

## 确定方向

1. 先看例子：打开 [`assets/design-examples.html`](../assets/design-examples.html)，或 [style-recipes.md](style-recipes.md) 里各配方的 a–d 图。配方按“看起来是什么样、怎么做”来写，不按行业分配；根据这份内容、受众、场合、素材和用户的偏好，判断哪些气质贴切。
2. 可以选一套为主，可以组合（一套定字体网格色彩，借别的配方一两个手法；不同章节用不同做法），也可以都不用、自定方向。组合的数量不设限，以成品协调为准：字体、色彩角色和对齐关系要贯穿全套。
3. 结合主题改编：在视觉定调里写明本项目为什么用这组颜色，依据可以是品牌、主要图像、内容主题、文化参考或希望传达的感受；示例色值只演示方法，不作默认主题，也不按行业自动分配颜色，用户的品牌、模板和明确偏好优先。从内容中提炼视觉母题，按真实内容量调整尺度。自定方向时同样需要概念、母题和明确的设计数值。暖白纸底、黑字加一抹橙红，是本技能示例里最常见、也最容易不假思索选中的组合；没有具体理由时不默认用它，白底、冷色、深色、大色块和品牌色都是同样正当的起点。
4. 读取 [typography.md](typography.md) 确定字体搭配与获取方式；读取 [imagery.md](imagery.md) 决定每页配什么图、怎么找或怎么画；读取 [anti-patterns.md](anti-patterns.md)，提前排除不该出现的做法。
5. 在 `planning.md` 写下视觉定调。需求明确时自主决定，不要求用户先挑风格；候选方向拿不准时，在代表页阶段并排比较（见 [visual-review.md](visual-review.md)）。

“高级、极简、科技感”不能指导制作。视觉定调至少写到下面的具体程度：

```markdown
## 视觉定调
- 概念：像医院走廊的导视系统：每一段流程一个分区色、一个超大编号，观众一眼找到自己在哪一段
- 色彩来源：门诊流程本来就按挂号、候诊、问诊、取药分区，导视的分区色让观众知道自己在哪一段；红色只留给“候诊最长”这一处
- 配方：自定；借 R1 的超大章节编号和 R15 的带圈编号
- 改编：分区色只用在编号、时间条和章节页的大色块上，正文区保持白底
- 参考调性：医院与机场的导视设计、交通时刻表
- 色彩：bg #FFFFFF｜ink #10242B｜ink-2 #4A5B63｜line #D8E2E6｜分区 #0F766E #2563EB #7C3AED #B45309｜强调 #B91C1C
- 字体：标题 鸿蒙黑体 Bold；正文 思源黑体 Regular / Medium；数字 Inter（表格用等宽数字）；PPTX 字体策略：稳妥（见 typography.md）
- 字号（px，1280×720）：展示 160｜标题 44｜小标题 26｜正文 22｜图旁标签 17｜来源 14
- 网格：12 栏，外边距 80，栏距 24，间距倍数 8
- 形状语言：大圆角色块做分区、细线做时间轴，无阴影
- 图片：候诊区与自助机的照片（find_images 搜开放许可），统一偏冷、提亮
- 插画与图标：flat 插画，主色随分区换色；节点用 Lucide 线性图标，2px、单色
- 高潮页：P1 封面、P4 一根时间条看全程、P9 改进前后
- 禁用：紫蓝渐变、每页都是卡片、图标墙、没有来由的暖白纸底
```

示例只用来说明需要写到什么程度，不能当作默认主题，也不要照抄它的配色和参考调性。没有参考配方时，“配方”一行写“自定”，其余各项照常写清楚。

## 设计数值

没有品牌规范时，从以下数值出发，按配方和内容调整，并把最终值写进视觉定调。

- **画布与网格**：默认 1280×720。外边距 64–96px（至少约为画布宽度的 5%），12 栏，栏距 24px，所有间距取 8 的倍数。同类元素共用对齐线，页面之间标题位置保持一致。
- **字号**：按 [typography.md](typography.md) 的字号阶梯。每页最大文字与正文的比例至少 2:1，高冲击页至少 5:1。
- **色彩比例**：主色或背景约 60%，辅助色约 30%，强调色不超过约 10%。背景不必是纯白，可用偏暖或偏冷的近白，或深色。
- **色彩角色**：定义背景 / 表面 / 主文字 / 次文字 / 弱化 / 线 / 强调 / 数据系列，全套只按角色用色，不临时取新颜色。HTML 写成 CSS 变量，PPTX 写成常量。
- **对比度**：正文对背景至少 4.5:1，大字至少 3:1；彩色数据还要用标签或形状区分，不能只靠颜色。
- **形状语言**：圆角、描边、阴影三者各选一种做法并全套统一。阴影只用于真实的层叠关系。

## 节奏

在策划稿中给每页标注能量：

| 能量 | 用途 | 处理 |
|---|---|---|
| 高冲击 | 封面、核心结论、最强证据、章节开场 | 一个想法，极大的尺度反差，主视觉或超大排版 |
| 标准 | 主要论证 | 明确焦点，配一组支撑证据 |
| 密集 | 数据明细、对比表、需要独立阅读的信息 | 编辑式层级；字号可以比正文小一档，但不低于 16px（12pt） |
| 呼吸 | 章节过渡、引言、停顿 | 大留白，极少文字 |

- 不连续出现三页以上能量与构图都相同的页面；为了并列比较而有意重复的除外。
- 密集页之后考虑安排一个呼吸页或高冲击页。
- 高潮页在策划时就确定，制作时优先投入。

## 根据内容构图

每页按以下步骤确定构图：

1. 先选最需要被看见的内容。焦点不等于每页都放巨大的数字，也可以是一组对比、一张照片或一条清楚的关系链。
2. 给焦点足够的面积、位置或对比，辅助信息围绕它组织。
3. 按理解顺序安排视线：第一眼看到什么，接着读到哪里，哪些细节应当弱化。

[layouts.md](layouts.md) 收录了常见页面任务的版式原型（目前 24 个，每个先说帮观众看懂什么，再给几种排法的成品图），可以作为构图起点。原型可以修改、组合；没有合适的就按上面三步自定构图，效果好的自定版式在全套中复用，也可以收进 layouts.md。

用共同的字体、色彩语义与对齐关系保持一致，用面积、位置、密度与素材制造变化。只有分组确实有意义时才使用卡片；连续比较页可以保留相同布局。

## 排版与留白

详细规则见 [typography.md](typography.md)。

- 先排最长的标题和最密的正文，验证字号、文本框和行距，再批量制作。
- 标题按语义断行，避免孤字，不拆开数字与单位，行首不出现句读标点。
- 同级内容共用基线和间距；检查文本框内边距，不能只对齐外框。数字列按位数或小数点对齐。
- 留白用于分组、突出与停顿，要有方向，不要四周均匀漂浮。图片可以出血，重要文字与数据留在安全区内。
- 内容拥挤时，先删冗词、重组，或在允许的页数内拆分；字号只在 [typography.md](typography.md) 的下限以上调整，不靠缩小字号塞进信息。

## 图片、图形与数据

- 每页配什么图、怎么搜开放许可的照片、怎么用和补画 SVG 插画、照片怎么处理、图标怎么用，见 [imagery.md](imagery.md)。
- 图表与表格的选型和美化默认值见 [charts.md](charts.md)。

两者的共同底线：

- 素材必须承担具体作用，事实性图片不能用虚构画面冒充。
- 标题、正文和数据单独制作；不生成带整页文字或图表的图片，再当作可编辑 PPTX 交付。

## 双格式与动效

HTML 和 PPTX 共享核心构图、视觉焦点与证据，但允许按各自的文本度量微调位置和换行。先验证主要视觉能在两种格式中成立。复杂装饰可以做成局部图片，但不能因此把需要编辑的对象变成图片。

HTML 动效用于强化叙事：入场依次出现、逐步揭示、数据描绘等（播放器支持见 [html.md](html.md)）。遵守减少动态效果的系统偏好；打印和静态 PPTX 保留完整信息。先检查静态页面，不用动画掩盖层级与构图问题。
