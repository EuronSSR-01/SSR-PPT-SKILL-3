# flat：扁平圆润

**样子**：纯色块，不描边；圆角；同一种颜色分深、中、浅三档表现受光面、背光面和玻璃；底部一道浅色椭圆阴影；人物不画五官。主色占大面积，强调色只给一两个关键部件（货车车头、仓库纸箱、地图定位针）。

**画面效果**：亲和、清楚、颜色饱满，远看也认得出是什么。适合讲场景、流程、链条，以及面向大众、客户或新人的页面；也可以只用一两张，给数据页加一个“主角”。

**搭配**：与圆角卡片、无衬线字体、明亮或浅色背景协调。和细线编辑风格、深色发布会风格放在一起时，先试一页：要么把插画换成同色系、降低饱和度，要么改用 `line` 风格。

所有插画画在 320×240 的画布上，地面约在 y=212；“场景大小”是拼场景时相对建筑的默认比例（建筑 = 1），写在每个 SVG 的 `data-scale` 里。
