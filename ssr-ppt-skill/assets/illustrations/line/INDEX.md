# line：线描

**样子**：深色线条勾轮廓（外轮廓 3 单位，内部细节 2 单位，圆头圆角），浅色底色块向右下错开约 7 个单位，每张只有一处强调色。和 `flat` 用同样的名字，换风格只改 `style="line"`。

**画面效果**：克制、清爽，像报告和说明书里的配图；线宽和 `assets/icons` 的线性图标接近，两者放在一起很协调。适合数据新闻、咨询商务、工程、学术等以文字和图表为主的风格：插画只做配角，不抢图表。

**搭配**：白色或浅色背景；深色背景上把 `ink` 换成浅色（如 `--ink F2F3F5`）。线条太细的时候不要把插画缩到 120px 以下。

这一套目前只有最常用的 8 个，是示范怎样建立第二种风格；需要的物体不在这里时，按 `../README.md` 的方法补画，或者整套用 `flat`。

| 名称 | 含义 | 场景大小 |
|---|---|---|
| `truck` | 货车、运输、配送 | 0.62 |
| `warehouse` | 仓库、仓储 | 1 |
| `factory` | 工厂、生产 | 1 |
| `store` | 门店、零售、网点 | 1 |
| `bank` | 银行、金融机构 | 1 |
| `city` | 城市、楼群 | 1 |
| `laptop` | 电脑、线上、系统 | 0.45 |
| `person` | 人物、员工 | 0.62 |
